每位白名单 UP 主独立记忆音量，播放器与扩展实时同步。

### 更新内容

- 白名单成员缺省音量为 70%，弹窗音量滑块只调整当前 UP 主。
- 在网页播放器调节白名单成员音量时，自动保存，并同步到该 UP 主的其他已打开视频。
- 已识别的非白名单视频允许自由调节音量；切换视频后重新应用扩展的非白名单音量，不将手动调节写入设置。
- 扩展滑块在拖动期间实时更新网页音量；识别期间与失败时仍保持低音量，不主动取消静音或开始播放。
- 白名单备份包含成员音量，合并保留已有备注与音量；旧名单和旧备份缺少音量时使用 70%。管理页显示成员记忆音量。
- 修复页面内切换视频及从首页进入视频时，原始页面地址影响识别和音量保存的问题。

### 安装与更新

下载附件 **bilibili-voice-breaker-0.3.0-chrome.zip**，Chrome 和 Edge 共用。首次安装请解压后通过浏览器扩展管理页加载已解压扩展。

更新时用新版文件覆盖原安装文件夹，在扩展管理页点击「重新加载」，并刷新 B 站视频页；保留原安装路径和扩展，避免卸载后丢失设置。旧名单成员保留，未记录独立音量的成员使用 70%。

附件 `.sha256` 文件用于校验安装包。GitHub 自动生成的 Source code 压缩包需要构建后才能加载。

### 验证与范围

已通过类型检查、生产构建、7 项单元测试和 6 项模拟浏览器测试，覆盖成员独立记忆、实时调节、页面内导航、多标签同步、导入导出与暂停恢复。模拟测试不等同于真实 B 站页面验收。

支持普通视频页的标准 HTML5 播放器；直播、番剧、稍后再看及特殊 HEVC 软解播放器暂不支持。扩展执行音量策略，不进行响度归一化或人声分离。设置保存在本机，无开发者后端或遥测。
