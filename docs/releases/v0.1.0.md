首个开源版本，支持桌面版 Chrome 和 Microsoft Edge。

### 功能

- 白名单 UP 主以设定的正常音量播放，其他 UP 主自动压低音量。
- 弹窗中一键添加当前 UP 主，独立管理页支持手动添加、备注、搜索和移除。
- 默认音量为白名单 70%、非白名单 1%，可分别调整，0% 即无声。
- 切换普通视频时重新识别 UP 主；识别期间或失败时保持低音量。
- 设置保存在本机，无开发者后端或遥测，采用 MIT 许可证。

### 安装

1. 下载附件 **bilibili-voice-breaker-0.1.0-chrome.zip** 并解压。此包供 Chrome 和 Edge 共用。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的文件夹。
4. 刷新 B 站视频页后使用。请保留安装文件夹，本安装方式不自动更新。

附件 `.sha256` 文件用于校验安装包完整性。GitHub 自动附带的 Source code 压缩包是源码，需要构建后才能安装。

### 当前范围

支持 B 站普通视频页的标准 HTML5 播放器。直播、番剧、稍后再看及特殊 HEVC 软解播放器暂不支持。这是按 UP 主设置音量的工具，不做自动响度匹配或人声分离。

自动测试使用模拟页面与接口，不等同于真实 B 站环境验收。接口变化或风控可能导致识别失败。查询投稿者时会把当前视频 ID 发送至 B 站接口，详见仓库隐私说明。
