# 真实页面验收

安装 `.output/chrome-mv3` 后刷新页面。先从低系统音量开始，选取两位不同 UP 主的视频，将其中一位加入白名单。

| 操作 | 预期结果 |
| --- | --- |
| 打开白名单外视频 | 识别期间与完成之后均为压低音量 |
| 在面板添加当前 UP 主 | 按正常音量播放；关闭后再打开面板仍保留 |
| 从弹窗点击「管理白名单」 | 在独立标签页打开名单，不在弹窗显示完整名单 |
| 在管理页移除当前 UP 主 | 视频立即压低，弹窗名单数量随之更新 |
| 在管理页通过 UID / 空间链接添加 UP 主 | 名单保留，重开管理页仍可见；已识别的视频即时应用 |
| 在管理页搜索名称或 UID | 仅显示匹配成员，不匹配时显示空结果 |
| 切换到其他 UP 主 | 撤销前一位的放行状态；未知时压低 |
| 快速连续切换视频 | 旧视频的识别结果不会放行新视频 |
| 切换分 P | 同一投稿者沿用同一规则 |
| 视频播完自动连播 | 根据新地址识别投稿者并重新应用规则 |
| 播放器清晰度切换 / 重新创建 | 新媒体元素仍按规则播放 |
| 在播放器中手动加大音量 | 启用时回到扩展设定值 |
| 先将播放器静音，再加入白名单 | 仍保持播放器静音 |
| 关闭扩展开关 | 恢复接管前记录的音量；之后播放器音量可自由调整 |
| 多个 B 站标签页打开时修改设置 | 所有普通视频页更新规则 |
| 断网 / 接口出错 | 保持低音量，面板提示识别失败 |
| 其他 UP 主音量设为 0% | 无声音 |
| 使用 HEVC 软解特殊播放器 | 面板提示未接管，不声称已降低音量 |
| 从首页进入普通视频 / 从视频返回首页 | 进入时接管，离开时释放 |

直播、番剧和稍后再看页面当前不适用。真实页面验收结果尚未记录。
