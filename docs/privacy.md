# B站UP音量白名单隐私说明

更新日期：2026-10-22

用户可在管理页将白名单 UID 与名称导出为本地 JSON 文件，或选择本地文件合并、替换白名单。导入导出均在本机完成，不上传文件，不包含音量与开关设置。

扩展在浏览器本机保存音量设置、开关状态以及用户添加的 UP 主 UID、名称或备注。这些设置不上传至开发者服务器，不跨设备同步。用户可在独立白名单管理页逐项移除名单成员；卸载扩展会由浏览器删除扩展的本机设置。

为了识别当前视频的主投稿者，扩展将当前普通视频的 BV 号或 AV 号发送至 B 站 `api.bilibili.com` 视频信息接口。B 站会收到该视频 ID 及请求所需的网络信息（例如 IP 地址）。扩展显式不携带账号凭据，不发送白名单、用户账号信息或其他站点浏览记录。接口响应中的投稿者 UID 与名称仅用于当前视频的规则匹配；用户选择加入白名单时保存在本机。

扩展没有自建后端、广告或分析统计，不收集视频音频，不读取登录凭据，不访问非 B 站页面内容，也不向开发者发送使用记录。

隐私问题可通过本项目开源仓库的 Issue 反馈。若数据处理方式发生变化，将同步更新本说明。
